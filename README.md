# MediBook

MediBook is a web application for online medical appointment scheduling.

## Project Overview

The application allows patients to view a doctor's availability and manage their appointments.

The project includes three user spaces:
- Patient
- Doctor
- Administrator

## Tech Stack

### Frontend
- React
- TypeScript
- Next.js
- Tailwind CSS

### Backend
- Python
- FastAPI
- SQLAlchemy
- Alembic

### Database
- PostgreSQL

### Tools
- Git and GitHub
- Docker
- Pytest
- Vitest
